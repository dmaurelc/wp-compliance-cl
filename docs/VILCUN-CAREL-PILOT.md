# Piloto recomendado — Vilcún Carel

El plugin está diseñado para instalarse sin acoplamiento al proyecto. Como primer piloto conviene revisar especialmente:

1. Formularios de contacto y de solicitud de certificación construidos con Bricks.
2. Datos como nombre, email, teléfono, mensajes y documentos adjuntos.
3. Submissions guardados por Bricks y sus plazos de retención.
4. Envío de correo mediante FluentSMTP y el proveedor SMTP configurado.
5. Datos de clientes/validaciones gestionados en WordPress/ACF.
6. Servicios externos detectados por el escáner en contenido, scripts o embeds.

## Primera configuración sugerida

- Completar responsable, RUT, domicilio y email de privacidad.
- Crear un tratamiento por cada flujo real, no por cada campo.
- Registrar proveedor de hosting, SMTP y cualquier servicio de analítica/marketing.
- Ejecutar el escáner y convertir los hallazgos relevantes en tratamientos/proveedores.
- Definir retención para submissions y documentos adjuntos.
- Generar política, centro de privacidad y canal de derechos.
- Revisar handles de scripts que deban condicionarse al consentimiento.

Este archivo es una guía de implementación técnica, no una evaluación jurídica del sitio.
